# 🤜 **Open-Coach** 🤛

☢️ In development ☢️

Open-Coach is an app for practicing ⭐ *ANY* ⭐ skill,
by having your very own digital coach *boss you around*, for free!

For example, you can use **Open-Coach** for:
- 🥊 Boxing, 🥋 Martial Arts, 🤼‍♂️ Wrestling, 🏋️ Working out
- 🎸 Guitar, 🥁 Drums, 🎻 Violin practice
- 🍳 Cooking, 👕 Washing, 🧹 House chores
- *...*

## How it works

Open-Coach relies on two main features of your 📱 phone:
- 🙊 Offline Text-To-Speech to announce things
- 🫨 Vibration to signal changes
 
The main tab is for you to get inspired by quotes and 🖼️ pictures of your choosing.

In the exercises tab houses your Exercise Groups, these are collections of exercises.
For now, there are:
- 🎶 Rhythmic Exercise - Uses phone vibration to set the rhythm ( eg.: Double-Jab to the body, pause, then deliver a massive Hook! )
- ❤️‍🔥 Intensity Exercise - Uses phone vibration to set intensity ( eg.: How hard you pull on a rope )
- 🫰 Reaction Exercise - Randomly gives you a task ( eg.: Run until coach says do 10 pushups )

The ⚙️ settings view is a JSON editor, where you can edit a lot of small details.

## Features
- 💰 Free
- 🛜 Offline
- 🔐 Private and Secure-ish
- 👐 Open Source
- 👨‍💻 and Fully Customizable!
